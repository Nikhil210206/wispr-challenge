# What I actually said

One file per Emergent step, named after the brief: `02-skeleton.md`, `04-unsqueeze.md`, and so on.

Paste the prompt exactly as Flow wrote it, before any fixes. Then add:

- **Fixed by hand:** what you corrected before sending (wrong words, ids, numbers).
- **Credits:** balance before → after.
- **Result:** did it do what the brief asked? What did you have to say again?
